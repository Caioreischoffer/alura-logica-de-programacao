# 🧠 Lógica de Programação com JavaScript

Repositório criado para reunir os projetos, exercícios e desafios desenvolvidos durante meus estudos de **Lógica de Programação com JavaScript na Alura**.

O objetivo deste repositório é registrar minha evolução nos fundamentos da programação, desde os primeiros conceitos de lógica até a criação de funcionalidades utilizando **JavaScript e manipulação do DOM**.

---

## 📚 Sobre o repositório

Os projetos presentes neste repositório foram desenvolvidos em diferentes momentos enquanto eu acompanhava os cursos de Lógica de Programação da **Alura**.

Durante as aulas, a Alura disponibilizou previamente a estrutura visual dos projetos, incluindo principalmente:

- HTML
- CSS
- Imagens e assets
- Estrutura inicial das páginas

Meu foco durante os estudos foi trabalhar principalmente na **lógica e no comportamento das aplicações utilizando JavaScript**, acompanhando as aulas e implementando as funcionalidades propostas.

Além dos projetos desenvolvidos durante as aulas, também realizei **desafios adicionais por conta própria**, aplicando os conceitos estudados para encontrar minhas próprias soluções.

> **Nota de transparência:** o design e a estrutura visual dos projetos não foram desenvolvidos por mim. Eles foram fornecidos pela Alura como material dos cursos. Minha participação está concentrada principalmente na implementação e prática da lógica de programação em JavaScript e na resolução dos desafios propostos.

---

## 🚀 Projetos

### 🎯 Jogo do Número Secreto

Jogo onde o usuário precisa descobrir um número secreto gerado pela aplicação.

Durante esse projeto foram praticados conceitos como:

- Variáveis
- Funções
- Condicionais
- Geração de números aleatórios
- Manipulação de elementos HTML
- Controle do fluxo da aplicação

📂 [`Jogo do Numero Secreto`](./Logica%20de%20Programacao/Jogo%20do%20Numero%20Secreto)

---

### 🎮 AluGames

Aplicação que simula uma plataforma de aluguel de jogos de tabuleiro.

O projeto trabalha principalmente com alteração dinâmica do estado dos jogos entre **alugado** e **disponível**.

Conceitos praticados:

- Funções
- Condicionais
- Manipulação do DOM
- `querySelector`
- `classList`
- Eventos
- Alteração dinâmica de textos e classes CSS

Também foram realizados desafios adicionais, como:

- Confirmação antes da devolução de um jogo
- Contagem da quantidade de jogos alugados
- Exercícios extras de lógica

📂 [`AluGames`](./Logica%20de%20Programacao/alugames)

---

### 🎁 Amigo Secreto

Projeto baseado na lógica de organização e sorteio de participantes para um amigo secreto.

Utilizado para praticar conceitos relacionados a:

- Arrays
- Funções
- Manipulação de dados
- Estruturas condicionais
- Interação com elementos da página

📂 [`Amigo Secreto`](./Logica%20de%20Programacao/amigo-secreto)

---

### 🛒 Carrinho de Compras

Aplicação que simula funcionalidades básicas de um carrinho de compras.

Durante o desenvolvimento foram praticados conceitos como:

- Captura de dados do usuário
- Operações matemáticas
- Manipulação de elementos HTML
- Funções
- Atualização dinâmica de valores
- Organização da lógica da aplicação

📂 [`Carrinho de Compras`](./Logica%20de%20Programacao/carrinho-compras)

---

### 🎟️ Ingresso

Projeto que simula a compra de ingressos com controle da quantidade disponível para diferentes setores.

Conceitos trabalhados:

- Funções
- Condicionais
- Conversão de valores
- Manipulação do DOM
- Controle de quantidade
- Validação de dados

📂 [`Ingresso`](./Logica%20de%20Programacao/ingresso)

---

### 🎲 Sorteador de Números

Aplicação para geração e sorteio de números utilizando JavaScript.

Entre os conceitos praticados estão:

- Números aleatórios
- Funções
- Arrays
- Estruturas de repetição
- Condicionais
- Manipulação do DOM

📂 [`Sorteador de Números`](./Logica%20de%20Programacao/sorteador-numeros)

## 💻 Como executar os projetos

### 1. Clone este repositório

```bash
git clone https://github.com/Caioreischoffer/alura-logica-de-programacao.git
```

### 2. Entre no diretório

```bash
cd alura-logica-de-programacao
```

### 3. Escolha um dos projetos

```text
Logica de Programacao/
```

### 4. Execute o projeto

Abra o arquivo `index.html` do projeto desejado em seu navegador.

Também é possível utilizar extensões como **Live Server** no Visual Studio Code para executar os projetos localmente.
